# Hebbar's Collection 🛍️

E-commerce website — React + Tailwind CSS frontend + Node.js backend.

---

## How to Run Frontend

```bash
npm install
npm start
```
Opens at → http://localhost:3000

---

## How to Run Backend

```bash
cd backend
npm install
npm start
```
Runs at → http://localhost:5000

---
